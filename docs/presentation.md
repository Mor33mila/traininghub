# Scaletta presentazione tecnica

Durata suggerita: 15-20 minuti. Personalizzare nomi, contributi e risultati effettivi del gruppo.

| Tempo | Contenuto | Demo / evidenza |
| --- | --- | --- |
| 0-2 min | Scenario, utenti e obiettivo | Problema dei dati formativi frammentati |
| 2-5 min | Architettura e persistenza | Diagramma servizi, database separati, API REST |
| 5-13 min | Percorso applicativo | Login; creazione corso e partecipante; iscrizione; conferma; presenza/assenza; dashboard |
| 13-16 min | Qualita' tecnica | Ruoli JWT, validazioni, errori, soglia frequenza e test |
| 16-18 min | Avvio e repository | `docker compose up --build`, Swagger e struttura Git |
| 18-20 min | Limiti e sviluppi | Test browser, migrazioni versionate e hardening pre-produzione |

## Preparazione

- Provare la demo su un database pulito e preparare una seconda iscrizione/dato di riserva.
- Verificare in anticipo Docker Desktop, credenziali, porte e pagine Swagger.
- Ogni componente del gruppo deve saper spiegare il proprio contributo e almeno il flusso end-to-end.
- Aggiornare questa scaletta dopo aver verificato i container; non dichiarare risultati non dimostrati.
