# Registro di utilizzo degli strumenti AI

## Voce di progetto

- **Strumento**: GitHub Copilot.
- **Obiettivo**: confrontare il repository con la guida del projectwork, individuare i passaggi UI non collegati e completare dashboard, setup container e documentazione.
- **Prompt sintetico**: "Controlla che ogni requisito minimo richiesto dal projectwork sia stato implementato"; successivamente: "ok risolvi tutto, e non pensare ai commit".
- **Verifiche svolte con assistenza**: esecuzione delle suite Maven dei quattro servizi; controllo sintattico Node.js degli script frontend; controllo dei file Compose e avvio Docker da ripetere su una macchina con Docker Desktop.
- **Interventi effettuati**: gestione UI delle iscrizioni e dei loro stati; form assenze; metriche dashboard; Dockerfile, Compose, bootstrap DB; CORS per il frontend containerizzato; documentazione tecnica e operativa.
- **Limiti**: l'ambiente di sviluppo non dispone del comando Docker, quindi i container non sono stati avviati; non sono stati eseguiti test browser automatizzati; diagrammi e documenti devono essere confrontati con la release finale.

Il gruppo deve leggere e comprendere le modifiche, ripetere le verifiche, annotare eventuali correzioni e approvare questa relazione prima della consegna. Non considerare questa voce una dichiarazione di revisione umana gia' avvenuta.
